## Overview

Version 1 of my personal portfolio website, developed to establish an online presence and showcase projects, technical skills, and contact information through a clean, responsive interface.

The website focuses on simplicity, accessibility, and performance while serving as a centralized portfolio for software development work and personal projects.

---

## Core Features

### Hero Section

A concise introduction highlighting professional background, interests, and areas of focus.

### About

Overview of personal background, technical interests, and career objectives.

### Skills

Organized presentation of technologies, programming languages, frameworks, and development tools.

### Projects

A curated collection of selected projects with descriptions, technologies used, and repository links.

### Contact

Direct access to professional contact information and social platforms.

### Responsive Design

Optimized layouts that adapt seamlessly across desktop, tablet, and mobile devices.

### Lightweight Architecture

Built entirely with vanilla HTML, CSS, and JavaScript, resulting in fast loading times and minimal resource usage.

## Getting Started

Clone the repository.

```bash
git clone https://github.com/AarjanAdhikari/portfolio-website-v1-.git
```

Navigate to the project directory.

```bash
cd portfolio-website-v1-
```


Open `index.html` directly in your browser or launch the project using a local development server such as **VS Code Live Server**.
